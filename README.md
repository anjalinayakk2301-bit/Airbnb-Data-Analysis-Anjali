# Airbnb NYC 2019 — Exploratory Data Analysis

A data analysis project exploring Airbnb listings in New York City using Python, Pandas, and Matplotlib.

## Project Overview

This project analyzes the Airbnb NYC 2019 dataset to understand patterns in:

- Listing prices
- Room types
- Neighbourhoods
- Number of reviews
- Availability
- Host listings

## Objectives

- Clean and prepare the dataset
- Explore Airbnb listing characteristics
- Compare prices across neighbourhoods and room types
- Identify popular neighbourhoods
- Analyze review patterns
- Examine relationships between numerical variables
- Communicate findings through visualizations

## Tools & Technologies

- Python
- Pandas
- Matplotlib
- Google Colab
- Jupyter Notebook (`.ipynb`)

## Dataset

The dataset contains **48,895 Airbnb listings** from New York City in 2019.

The analysis includes information such as:

- Neighbourhood
- Room type
- Price
- Minimum nights
- Number of reviews
- Reviews per month
- Availability
- Host listing count

## Key Insights

- Manhattan has the highest average listing price among the five neighbourhood groups.
- Entire homes/apartments have the highest average price among the room types.
- Manhattan and Brooklyn contain the largest numbers of listings.
- The price distribution is strongly right-skewed due to a small number of very expensive listings.
- Approximately 79.4% of listings have a recorded review date.
- Price and number of reviews have a very weak linear relationship.
